# ☕ Portafolio de Desarrollo de Software Puro en Java (V1.0)

¡Hola! Este repositorio es mi espacio oficial de experimentación y aprendizaje enfocado en el desarrollo de software puro, lógica de algoritmos y programación orientada a objetos utilizando **Java**. 

Después de trabajar con sistemas embebidos y robótica (C++ en Arduino), decidí dar el salto hacia la programación lógica pura. Aquí iré almacenando de forma modular todos los códigos, programas interactivos y mini-juegos de consola que desarrolle de manera independiente durante mi bachillerato en Durango, México.

---

## 🚀 Enfoque del Repositorio
A diferencia de la robótica, donde el código controla pines físicos, los programas de este repositorio están diseñados para:
* **Procesamiento de Datos:** Recibir valores directos ingresados por el usuario y transformarlos en información útil visible en pantalla.
* **Dominio de Sintaxis Estricta:** Validar y dominar las reglas de tipado fuerte de Java (estructuras de clases, control de mayúsculas en comandos del sistema y manejo preciso de llaves `{}`).
* **Arquitectura Modular:** Mantener cada programa encapsulado de forma limpia y eficiente para construir una base sólida de desarrollo.

---

## 🛠️ Herramientas y Lenguajes
* **Lenguaje Principal:** Java SE (Standard Edition)
* **Herramientas de Desarrollo:** Compiladores en línea (OnlineGDB) con sistemas de autocompletado de sintaxis en tiempo real.
* **Control de Versiones:** GitHub para la gestión y respaldo de código fuente (`.java`).

---

## 📁 Estructura de Aprendizaje Continuo
En este espacio se irán integrando los siguientes módulos lógicos:
1. **Lógica Condicional Básica:** Control de flujos mediante estructuras `if / else` y manejo de variables primitivas (`int`, `String`).
2. **Interactividad Dinámica:** Captura de datos en tiempo real mediante el teclado utilizando la herramienta `Scanner`.
3. **Estructuras de Control Avanzadas:** Bucles lógicos e interactivos para la creación de algoritmos complejos y mini-juegos clásicos de texto en consola.
